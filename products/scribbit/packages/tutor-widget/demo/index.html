Ask Blockspace

A retrieval-grounded tutor for Bitcoin blockspace — fees, weight, inscriptions, Taproot, the mempool — that cites its sources. It never gives price or investment advice and never asks for keys or seeds. This page runs the widget in offline demo mode.

Embed it (see the package README): <script type="module" src="…/ask-blockspace.js"></script> then <ask-blockspace api-base="https://your-tutor-api"></ask-blockspace>.

Machine guide: llms.txt. Policy: never price, never keys.
